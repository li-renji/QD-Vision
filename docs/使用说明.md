## 三、怎么用（5 步上手）

### 1. 新建工程

首页点 **「＋ 新建工程」**，填个名字（如「我的第一个剪辑」），确定。

### 2. 导入素材

- **拖拽**：把视频/图片/音频文件直接拖进左侧「素材库」
- **或点击**素材库里的 **「导入素材」** 按钮

支持的格式：MP4 / MOV / WebM / 图片 / 音频 / GIF

> ⚠️ **素材不会上传**。文件只走 `Blob → IndexedDB`，全程留在你本机浏览器里，断网也能用。这是这个项目的核心卖点。

### 3. 剪辑

| 操作 | 怎么做 |
|---|---|
| **分割** | 选中片段 → 顶部 **✂ 分割**（播放头需在片段中段，两侧各留 ≥100ms） |
| **删除 / 复制 / 粘贴** | 顶部工具栏对应按钮 |
| **调整时长** | 拖片段两端的手柄 |
| **变速** | 选中片段 → 右侧属性面板「变换」区 |
| **画中画** | 素材库里点 **📎** 图标，把片段作为上层叠加 |
| **加文字** | 底部 **「＋ 新增轨道」** → 选「文字」 |
| **多轨** | 默认 1 视频 + 1 音频轨，可增删视频/音频/文字轨 |

### 4. 预览

中间画布实时渲染。底部时间线上方是播放控制（⏮ ⏪ ▶ ⏩ ⏭），**速度** 下拉可调 0.25×~4× 播放。

### 5. 导出

右侧属性面板 → 调好分辨率/帧率/格式 → 点 **「开始导出」**。

| 能力 | 状态 |
|---|---|
| H.264 / VP9 / AV1 | ✅ 可用 |
| AAC / Opus | ✅ 可用 |
| HEVC | ⚠️ 部分浏览器不支持，会自动降级 |

导出完成后直接下载到本地，不经过服务器。

> 首次导出建议先试一个 10 秒的小片段。真实编码路径（尤其 HEVC 与音画同步）还需用真实素材验证过。

## 四、导入已有工程文件

首页 → **「导入工程文件」** → 选一个 `.clipcut.json`。

如果这个工程文件有数据不一致的地方，导入后会弹一条提示「工程文件存在 N 处不一致数据，已自动修正（时长已按素材区间重算）」—— 这是本轮刚做完的功能（FR-063⑦）。正常工程不会看到这条提示。

---

## 五、数据存在哪

工程和素材都存在**浏览器的 IndexedDB** 里，不在项目目录里。

⚠️ **换浏览器 / 清缓存 = 工程丢失**。重要工程建议用「导出工程文件」备份成 `.clipcut.json`。

## 七、常见问题

**Q：打开是空白页？**
A：硬刷新（Ctrl+Shift+R）。浏览器要求 Chrome/Edge 111+，Safari 16.4+，Firefox 建议走 MediaRecorder 兜底。

**Q：导入视频后预览是黑的？**
A：MP4 解码依赖浏览器 `VideoDecoder`，用 Chrome/Edge 打开；Safari 支持有限。

**Q：导出失败？**
A：看右侧「编码能力」矩阵 —— 绿色=可用。H.264+AAC 是最稳的组合。

**Q：分割按钮点不动？**
A：播放头必须落在选中片段的**中段**（两侧各留 ≥100ms，即最短片段的边界）。把播放头拖到片段中间就亮了。这是设计如此，防止分割出无效片段。

**Q：想让 AI 功能真正能用？**
A：见 `docs/ai/provider-api.md` —— 实现一个 `AIProvider` 接口就能挂上去（本地 Whisper / Ollama / 云端 API 都可以）。
